# Dokumentation

## Inhalt

- `Klassendiagramm_Fahrschule.md` - Entwurfsskizze, von Hand erstellt
  vor dem Programmieren.
- `Klassendiagramm_ReverseEngineering.md` - dasselbe Modell, automatisch
  aus den Quelldateien in `Aufgabe4_Eigenschaften` gelesen.
- `UML_ReverseEngineering.png` - das gezeichnete Diagramm als Bild,
  mit vollem Datenumfang. Das ist die Abgabedatei fuer Aufgabe 3.

## Legende im Diagramm

- `+` oeffentlich, `-` privat
- `«nur lesbar»` Eigenschaft ohne Setter, also Read-Only oder berechnet
- `«geprueft»` Setter prueft den Wert und lehnt ungueltige Eingaben ab
- `1` und `*` an den Pfeilen zeigen, wie viele Objekte beteiligt sind
